Forecasts each GTA VI PS5 trophy's Exophase earn rate at the target by splitting the rate into its two moving parts: it collapses the read history to distinct page-refresh states, forecasts the tracked player count and each trophy's implied earner count separately in log space against log-time with shrunk per-trophy slopes, and recombines them into logit-scale Gaussian quantiles, with a dilution prior for the single-state stale-page case.

## Run it

```sh
MAKEFUN_INPUT_DIR=input MAKEFUN_OUTPUT_DIR=out python3 main.py
```
